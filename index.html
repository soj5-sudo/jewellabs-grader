01

ML automated diamond grading.

Software and a scanning machine. A polished stone goes in, sensors read it under controlled conditions, a model grades it, and a structured record comes out.

The software runs on its own for houses that already image their goods. The machine adds the controlled conditions and the throughput.

02

How it works.

  1. 01LoadThe stone drops into a sealed chamber. Outside light never reaches it, which is why the numbers repeat.
  2. 02LightCalibrated arrays cycle through brightfield, darkfield and raking light. A 365 nm pass reads fluorescence.
  3. 03MeasureStructured light maps the facets. A load cell takes carat weight on the same stage.
  4. 04SeparateA spectrometer reads the optical signature. That is what tells natural from CVD and HPHT.
  5. 05GradeThe model assigns every category that carries price, each with a confidence value.
  6. 06RecordA fingerprint record is written. Everything downstream is built from it.

05

The paperwork builds itself.

A second model reads the records and assembles the filing, so the file is done while the goods are still on the desk. If a stone's paperwork and its scan disagree, it blocks there instead of at the border.
